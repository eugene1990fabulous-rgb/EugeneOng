## Before publishing

- The property card photos are temporary design imagery. Replace them with photos you have permission to use.
- The video player embeds your current website's galleries; visitors can choose a clip there. A fallback link opens the gallery directly if the frame is blocked. For a video hosted directly on this site, replace the gallery links with your own YouTube, Vimeo, or MP4 source.
- The upload picker is a local preview only. It does not publish or store the selected video.
- The enquiry form opens a prefilled WhatsApp message addressed to you; the visitor reviews and sends it in WhatsApp.
- The site has no database or backend. Listing cards link to PropertyGuru for full details and current availability.
- Listing prices and availability can change. Confirm each live listing before promoting it.

## Free hosting with GitHub Pages

GitHub Pages can host this static site from a public repository on GitHub Free. Create a public repository, upload `index.html` and this README, then choose **Settings → Pages → Deploy from a branch** and select the `main` branch and `/ (root)` folder. GitHub publishes the site at the URL shown in its Pages settings. See the [GitHub Pages quickstart](https://docs.github.com/en/pages/quickstart).

To use `eugeneongproperty.com` as the new site's address, its domain DNS and hosting settings would need to be changed. Do that only when you're ready to move the domain away from the current website; this package does not change your live site or domain.
